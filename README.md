# Aniket Chaudhary — Content Writing Portfolio

Run through XAMPP Apache at http://localhost/testing/aniket-prof/. No npm install or build is required.

The animated portfolio has been personalized from Aniket’s supplied resume and previous CopyWithAniket Google Sites portfolio. The resume is the source for current employment dates, education, contact details, and performance metrics; older biography details and published sample links come from the previous portfolio. The separate 50K and 70K traffic statements in the resume are not added together; the specific 70K NYGGS result is used.

Main files: `index.html`, `assets/main.js`, `assets/styles.css`, `assets/writer.css`. Writing rooms: `seo-content/`, `website-copy/`, `social-ad-copy/`, `email-scripts/`, and `creative-writing/`. Old room paths redirect to the corresponding writing pages. `.htaccess` handles direct visits to `/home`, `/work`, and `/my-story`.

The contact form opens a prepared email to ch.aniket12@gmail.com; it does not submit to a backend. The downloadable resume is `downloads/Aniket-Chaudhary-Resume.pdf`. External publication and social links are retained from the supplied sources; availability and third-party changes are controlled by their owners.

The underlying animated layout is adapted from the original Rishi Thakor reference. See `legal/` for credits and open-source licences. Removed template files and unused media are archived in `.qa/unused-assets/`; pre-cleanup source copies are in `.qa/cleanup-backup/`. These folders are development backups.

Certificates have a dedicated homepage section at `/certificates`, styled in `assets/certificates.css`. Three source credential links are shown separately from the ongoing AI SEO course. Header, mobile menu, and footer navigation link to this section.

The dedicated `/tools` section groups 17 tools from the supplied resume and old portfolio by research, editing, AI, and publishing. Styles are in `assets/tools.css`.

The `/novel` section features Deva: A Part of Me, written by Apoorva Bhatnagar and edited by Aniket Chaudhary. The original cover and publisher description come from the Apple Books listing; editing credit is also confirmed by Lulu. Styles: `assets/novel.css`.
